Wire Data Templates

Controlled wire specification spreadsheets for Power Wire Analysis external data mode.

← Back to Hub · Power Wire Analysis

Controlled engineering source data: These templates provide programme-governed wire catalog data for the Power Wire Analysis calculator. Populate, approve, version-control externally, then load in External controlled wire spreadsheets mode on the calculator.

What these templates are

Multi-sheet Excel workbooks containing metadata, AWG resistance tables, thermal/derating references, advanced analysis notes, validation case placeholders, and change history — aligned with the site wire data schema (pwa-wire-data-schema.js).

Each template is pre-filled with manufacturer seed data matching the built-in catalog (for traceability). You may load a spreadsheet without DATA_LOCKED; set it to YES when the file is formally approved controlled source data.

How to fill in and approve

  1. Download the template for your wire family.
  2. Review the Metadata and AWG_Data sheets against the approved manufacturer datasheet.
  3. Complete Prepared by, Checked by, and Approved by on Metadata.
  4. Record changes on Change_History.
  5. Optionally set DATA_LOCKED to YES when the spreadsheet is formally approved controlled source data.
  6. Store the file in your programme configuration management system.

How to load into Power Wire Analysis

  1. Open Power Wire Analysis.
  2. Expand Wire Data at the top of the page (or Project Folder / Reports as needed).
  3. Select External controlled wire spreadsheets.
  4. Click Load wire specification spreadsheet and choose your approved file.
  5. Confirm validation status shows Validated (warnings may appear if DATA_LOCKED is not YES).

Invalid spreadsheets are rejected and calculations revert to internal built-in data. The data source banner above the workflow panel shows which mode is active.

Internal vs external data mode

Mode Source When to use
Internal wire specifications Built-in site catalog (KP260, Raychem 55A0811) Default safe mode, training, and quick analysis
External controlled wire spreadsheets Programme-approved Excel templates from this page Certification support, customer-specific approved wire data, audit trail

Browser limitations

Power Wire Analysis runs in the browser. Folder read/write uses the File System Access API where supported (Chrome, Edge). Other browsers use manual file upload and download. The site does not upload wire data or project files to a server.
